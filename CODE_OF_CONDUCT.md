# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and keep criticism on the work rather
than the person. Harassment of any kind is not accepted, in any project space.

This repository holds attack prompts and adversarial examples because it tests
defences against them. Discussing those is welcome. Using them against anyone is
not.

To report a problem, contact the maintainer privately through the contact options
on their [GitHub profile](https://github.com/VicoAritonang). Reports are kept
confidential.
